# Risman Journal🧶

> *We Are All Threads of the Same String.*

A minimalist psychology journal exploring the threads of human experience through research, reflection, and dialogue.

Risman brings together perspectives from:

* Cognitive Psychology
* Child & Adolescent Psychology
* Personality Psychology
* General Psychology
* Philosophy of Psychology

## Features

* Editorial-inspired minimalist design
* Eight published issues
* Read issues directly in the browser
* Responsive across desktop, tablet, and mobile
* Light & dark themes
* Optimized for GitHub Pages and Vercel

## Philosophy

The Persian word **Risman** (ریسمان) means a string woven from many smaller threads. We see it as a metaphor for the human mind—formed through the intertwining of experiences, emotions, memories, and environments.

> *A string into the depths of the mind.*

* HTML5

* JavaScript
